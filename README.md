## 📌 About the Project

This project focuses on **data cleaning, exploratory data analysis, and data visualization using Python**. The Seaborn Taxis dataset is used to explore taxi trip information and understand patterns in fares, trip distances, payment methods, tips, and pickup locations.

The notebook covers missing-value handling and creates different visualizations using Pandas, Matplotlib, and Seaborn to represent the data clearly.

## 🎯 Topics Covered

- Loading and exploring the Taxis dataset
- Understanding dataset dimensions, data types, and descriptive statistics
- Identifying missing values and calculating missing-value percentages
- Handling missing values in numerical and categorical columns
- Converting pickup timestamps to datetime format
- Cleaning data by removing rows with missing critical values
- Creating visualizations using Matplotlib, Pandas, and Seaborn
- Exploring relationships between taxi fares, trip distances, tips, and payment methods

## 📈 Visualizations Created

### Using Matplotlib and Pandas
- Line Chart – Fare Over Time
- Bar Chart – Total Fare by Pickup Borough
- Pie Chart – Distribution of Trips by Payment Method
- Histogram – Distribution of Trip Distance
- Box Plot – Tip Amounts by Pickup Borough

### Using Seaborn
- Count Plot – Number of Trips by Pickup Borough
- Scatter Plot – Relationship Between Distance and Fare
- Heatmap – Correlation of Numerical Variables
- Pair Plot – Relationships Among Numerical Variables
- Violin Plot – Fare Distribution by Payment Method
